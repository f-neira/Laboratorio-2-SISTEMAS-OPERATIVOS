# Laboratorios Sistemas Operativos — Paralelo 301

Este repositorio contiene los **archivos a utilizar** en los laboratorios del curso.

## Selecciona la rama correspondiente

Cada laboratorio tiene su propio conjunto de archivos en una rama. Debes **seleccionar la rama correspondiente al laboratorio que vas a resolver**:

| Rama            | Contenido                                |
| --------------- | ---------------------------------------- |
| `laboratorio-1` | Archivos a utilizar en el Laboratorio 1. |
| `laboratorio-2` | Archivos a utilizar en el Laboratorio 2. |

### Cómo cambiar de rama

Desde GitHub, usa el selector de ramas en la parte superior del repositorio y elige `laboratorio-1` o `laboratorio-2`.

Desde la terminal:

```bash
git fetch origin
git checkout laboratorio-1   # o laboratorio-2
```
